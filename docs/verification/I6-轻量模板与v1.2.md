## 3. v1.2.0 发布说明草稿

> 发布前由维护者确认；以下为草稿。

**v1.2.0 复习版**

学完一门课，能复习、能自测。

**新功能**
- **课程概念表**：整门课的概念汇总成一张表，标出每个概念出现在哪几集，带回看链接；可以勾选已掌握（#49–#53）
- **课程自测与复习模式**：汇总各集自测题；对 Agent 说“考考我”，一次一题，答完再给答案和回看链接，不需要重新提供视频链接
- **讲解体笔记**：小节先抛问题、再讲清楚、节末一句“记住这个就够了”；新增本讲目标、本讲小结、面试速答式自测题；修正两处语雀不兼容写法（#54）
- **短视频轻量笔记 `brief`**：抖音 / 小红书 5 分钟以内的视频默认只写几条能复述的要点和可选细节，不再硬凑小节（#56、#57）
- **截图改为候选网格**：先按画面切段、剔除只有讲师在讲的空画面，把写完、没被挡住的候选帧拼成带编号的网格，由 Agent 按图注挑选。盲评中能佐证图注的截图从 68% 提到 95%（#60）
- 可汗学院微观经济学前 15 集样例按新模板重跑（#59）

**已知限制**
- 整门课只实测过 15 集，40 集以上未实测
- 复习模式还没有和真人完整走过一次
- 语雀里相对路径的笔记链接不能跳转；在语雀里勾选不会回写到本地概念表
- `brief` 只有离线测试，未在真实短视频上实测
- 截图：幻灯片课盲评 80%（逐步展开的动画页容易选早），教室录像与手写板为 100%；整集不变的画面会被当成背景不出图
- YouTube 原语言字幕的真实请求未测（只有离线测试）

**升级**
- `git pull` 即可，**没有新增依赖**
- 旧笔记仍能通过门禁（讲解体新规则只报 warning）
- 只写 `t` 的旧截图清单照常可用；推荐改为写 `range`，见 SKILL.md 第二步半

# 本机定时冒烟

- 关联：#12（W3 后段）
- 为什么在本机跑：W1 实测，B站和 YouTube 在 GitHub Actions 的机房 IP 上会被风控（见 `docs/verification/W1-技术验证.md`）。冒烟只能在家用网络的本机跑，Actions 上只保留手动触发的 `smoke-probe.yml`。

## 跑什么

| 项 | 说明 |
|---|---|
| 链接 | `references/smoke_urls.json`，每个平台 3 条公开链接 |
| 平台 | 默认 B站、抖音、小红书；YouTube 需要代理，暂不跑 |
| 内容 | 只取元数据、字幕和视频地址，不下载整段视频（抖音多读 64KB 确认地址可用） |
| 频率 | 每周二、周五 20:00，发版前手动再跑一次 |
| 合格线 | 整体成功率 ≥ 95%（不含链接失效） |

## 失败分两类

| 类别 | 判断依据 | 处理 |
|---|---|---|
| ⚠️ 链接失效 | 提示里有 `xsec_token`、“作品不可见”、“稿件不可见”等 | 换链接即可，不算平台故障；小红书要从网页搜索结果里重新取令牌（见清单的 `_说明`） |
| ❌ 平台故障 | 其他失败：风控、接口变动、签名失效 | 需要修代码；B站是一级平台，7 天内修复 |

## 安装（Windows）

建议单独克隆一份仓库专门跑冒烟，`git pull` 不会影响日常使用的那一份：

```powershell
git clone https://github.com/lucky-Luor/bilibili-douyin-notes.git D:\bdn-smoke
cd D:\bdn-smoke
pip install gmssl                      # 抖音签名依赖
python scripts\smoke_local.py run --no-pull      # 先手动跑一次，确认能用
python scripts\smoke_local.py install            # 注册定时任务 bdn-smoke（每周二、五 20:00）
```

- 定时任务只在你登录 Windows 时运行，不需要保存密码；用 `pythonw.exe` 启动，不弹窗口
- 改时间：`python scripts\smoke_local.py install --days MON,THU --time 21:30`（会覆盖原任务）
- 删除：`python scripts\smoke_local.py uninstall`
- macOS / Linux：`install` 只打印一行 crontab 配置，自己加进 `crontab -e`

## 看结果

| 文件 | 内容 |
|---|---|
| `reports/last-status.json` | 最近一次的时间、退出码（0 = 没有平台故障）、整体成功率、报告文件名 |
| `reports/smoke-<时间>.md` / `.json` | 每次的完整报告；最多保留 40 个文件（约 20 次） |
| `reports/last-run.log` | 最近一次的完整输出，排查用 |

`reports/` 已在 `.gitignore` 里，不会提交。

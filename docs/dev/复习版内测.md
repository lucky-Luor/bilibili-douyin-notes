# 复习版内测说明

I5 提供课程级概念表与课程自测，课程模型与 CLI 已在本地实现可用；这是 v1.2 的前段，尚未发布 v1.2。说明供用户本人邀请的 1–2 位内测用户使用，Agent 只编写说明，不代发邀请。

本地完整离线测试与 UTF-8 模式均为 854 项通过、5 项跳过；40 篇离线性能用例耗时约 0.09 秒，不代表 40 集实课验收。15 集程序验收通过；界面显示与真人三题复习尚待验证。详细结果和远端交付状态见 [I5 验收记录](../verification/I5-概念表.md)。

## 准备什么

- Python 3.10+、支持 Agent Skills 的 AI Agent，以及本项目 SKILL；安装与视频处理依赖见 [README](../../README.md)。复习本身不新增依赖。
- 一门公开可访问的 B站分P课或合集；已有课程可直接使用含 `course.json` 和至少一篇已完成笔记的课程目录，不必重做。原有 I3 / I4 清单兼容。
- 复习已有课程时可先复制课程目录再试。查看 Markdown 可用 VS Code、Obsidian 或语雀；路径含中文、空格时保留命令中的引号。

以下命令在项目根目录运行；`<课程目录>` 替换为实际路径。Agent 执行时使用安装目录下的脚本绝对路径。

## 怎么跑一门课

已有完成笔记的课程直接跳到下一节。新课程先做环境自检，再让 Agent 规划：

```bash
python scripts/doctor.py --platform bilibili --json # 按提示修复失败项后再处理视频
python scripts/course_plan.py plan "<B站链接>" "<课程目录>" # 查看清单、预估与范围确认文案
```

Agent 原样展示确认文案，等你选择范围再开始。下面以确认前 3 集为例；使用 Obsidian 可将模板改为 `v4-obsidian`，英文原声课确认后将语言改为 `en`，自动检测用 `auto`。

```bash
python scripts/course_plan.py start "<课程目录>" --first 3 --template v4 --asr-lang zh # 确认范围后启动
python scripts/course_plan.py next "<课程目录>" # 让 Agent 按返回步骤逐集制作笔记、填深链并通过门禁
```

每集完成后由 Agent 调用 `mark … done --note …`，失败则记录原因并继续。再次运行 `next` 可续跑；结束后 Agent 原样转述完成回执，保留课程索引、概念表、课程自测及失败集补跑信息。只有你同意才清理缓存。

## 怎么用概念表和课程自测

```bash
python scripts/course_plan.py concepts "<课程目录>" # 生成或刷新概念表.md、课程自测.md
python scripts/course_plan.py concepts "<课程目录>" --check # 只检查、不写文件，有错误时退出码为1
python scripts/course_plan.py concepts "<课程目录>" --unmastered # 只读返回没掌握的概念与对应题目
python scripts/course_plan.py concepts "<课程目录>" --master "机会成本" # 标记已掌握并刷新，可重复传入名称
python scripts/course_plan.py concepts "<课程目录>" --unmaster "机会成本" # 取消掌握标记并刷新
```

`--check`、`--unmastered`、`--master/--unmaster` 三组互斥。汇总覆盖课程中所有 `done` 且有笔记路径的集，不受当前所选范围限制；至少先完成一集。只汇总已有概念、定义、题目与答案，不生成新题，不修改原笔记或单集模板。

- `概念表.md`：查看概念在哪几集、哪一节出现，点击笔记或回看链接。合并按名称规范化匹配，不自动合并同义词；不同定义保留其它集的说法。
- 掌握后把概念行的 `+ [ ]` 改为 `+ [x]`。重新生成会保留勾选，并备份到 `course.json`；删掉概念表后重新生成可从备份恢复。文件读不出或勾选格式损坏时拒绝覆盖，先备份，再按“原因 / 影响 / 下一步”处理。
- `课程自测.md`：答案不折叠，手动自测先遮住答案。至少勾选一个概念并刷新后，“先复习”才单列没掌握的题；下面的“全部题目”仍保留所有题。无勾选时会提示先勾选。
- 回看时间来自原笔记的时间索引；题目使用对应概念在同一集首次出现的时间点。没有深链或时间点时按文件提示回到笔记，不补造跳转。

课程索引和完成回执都有两个文件的入口。`mark`、`verify`、`next` 结束和 `index` 会自动刷新；刷新失败返回 `review_warning`，课程处理继续，按提示修复后重跑 `concepts`，再用 `--check` 检查。检查只报缺失等问题，跳转内容是否准确还需实际点开核对。

## 怎么用复习模式

把课程目录告诉 Agent，然后说“考考我这门课”“复习这门课”或“我哪些没掌握”，无需再次提供视频URL。

1. Agent 运行 `concepts --unmastered`；只问哪些没掌握时列概念名，要自测时一次只出一道已有题，先不给答案或泄题提示。
2. 你答完后，Agent 对照原答案说明对错与遗漏，附回看和笔记链接；没有时间点时只给笔记链接并说明。
3. 答对或说“这个我会了”，Agent 先问“要标记为已掌握吗？”，你同意后才运行 `--master`；拒绝或未回复则不标记。

没有题目时如实说明，不临时编题；没有已完成笔记时先完成至少一集。`--unmastered` 最多返回 50 个概念，出现 `truncated:true` 表示结果未覆盖全部。

## 五个反馈问题

1. 概念合并对不对？有没有同名误合并或同义概念遗漏？请给出概念名与集号。
2. 回看跳转准不准？是否打开正确分P和位置？请附对应概念或题目及链接。
3. 勾选是否方便？重新生成是否保留？你使用哪个编辑器或导入工具？
4. 自测是否有用？一次一题、答后讲解与回看能否帮助找出没掌握的内容？
5. 最想增加什么功能？请说一个最影响你复习的需求。

# 错误分支清单（W3 前段盘点）

- 盘点日期：2026-11-02，基于 main `aa82fef`
- 范围：`bili_fetch` / `douyin_fetch` / `xhs_fetch` / `yt_fetch` / `bili_transcribe` / `bili_screenshot`
- 目标：每个失败都说清**原因 / 影响 / 下一步**（三段式，见 `scripts/_hints.py`），已完成的部分不白费
- 关联：#12

## 统一规则

| 场景 | 用法 | 效果 |
|---|---|---|
| 不可恢复（链接解析失败、用户输入有误） | `hint_exit(原因, 影响, 下一步)` | `SystemExit`，只打印三段文案，不打印堆栈 |
| 可恢复（单集失败、可降级） | `raise HintError(...)` | `RuntimeError` 子类，现有 `except Exception` 照常捕获，`str(e)` 即三段文案；JSON 摘要用 `e.to_dict()` |
| HTTP 错误 | `explain_http(状态码, 平台, 影响)` | 412 / 403 / 404 / 429 / 461 / 471 有固定解释 |
| B站业务码 | `explain_bili_code(code, message, 影响)` | -404 / 62002 / 62004 / 62012 / -403 / -412 / -352 / -101 有固定解释 |
| 抖音无作品数据 | `explain_douyin_filter(响应, 影响)` | 有 `filter_detail` → 作品不可见；没有 → 签名失效 |
